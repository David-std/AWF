## New code map

- `domain/agent_execution.py`: finite typed model task and provider observations.
- `application/ports.py`: provider-neutral `AgentExecutionPort`; `application/commands/run_agent.py`: monotonic elapsed measurement and SHA256 hashes of actual bytes.
- `adapters/models/ollama_local.py`: strict loopback Ollama HTTP; GET /api/tags before/after for provider-reported digest consistency and POST /api/generate; bounded bytes/timeout.
- `adapters/models/offline_fake.py`: test-only fake, correctly marked not executed network.
- `cli/main.py`: `awf agent-run PROMPT --model MODEL --allow-local-inference`; stores generated bytes in ignored content-addressed `.awf/agent-execution/blobs/`, content-free metadata `.awf/agent-execution/receipts/`. The command requires explicit flag.
- `tests/unit/test_agent_execution.py`: positive and adversarial tests for fake-vs-HTTP classification, malformed bytes/parameters, HTTP digest changes, model mismatch, clock regression, CLI no-opt-in, private output, symlink refusal.
- `docs/LOCAL_AGENT_EXECUTION_S2.md`, ADR-0034 and AWF-R044 traceability.
